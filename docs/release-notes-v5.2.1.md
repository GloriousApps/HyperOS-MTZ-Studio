# HyperOS MTZ Studio v5.2.1

## Fixes

- Root MTZ Import module inspection and installation are now available for every detected Xiaomi Themes version, rather than a small version whitelist.
- Fresh-system recovery no longer hides the root module controls merely because Xiaomi Themes has not been launched yet.

## Device recovery

If themes restored from cloud backup cannot be applied:

1. Enable the Xiaomi Themes package.
2. Install or update the Root MTZ Import module.
3. Restart the phone once so the Zygisk bridge is loaded.
