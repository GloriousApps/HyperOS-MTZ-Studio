# HyperOS MTZ Studio v5.2.0

## Changes

- Removed the experimental image OCR translation pipeline and its native Paddle/ONNX dependencies.
- Theme translation now changes only supported text resources and no longer modifies raster artwork.
- Added root import-module support for Xiaomi Themes `3.0.5.19`.

## Notes

- The Root MTZ Import module must be installed and the phone restarted before it becomes active.
- Xiaomi Themes must be enabled before its local-theme integration can be used.
