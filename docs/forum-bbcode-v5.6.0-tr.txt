[SIZE=5][B]Tema Yöneticisi uyumluluğu[/B][/SIZE]

MTZ Studio, kurulu Xiaomi Temalar sürümünü ve cihazın runtime durumunu çalışma anında doğrular.

Desteklenen çalışma yolları:

[LIST]
[*][B]Global runtime:[/B] Xiaomi Themes `3.4.1.23-global`
[*][B]Non-Global runtime:[/B] Xiaomi Themes `11.5.3.1`
[*][B]Theme Manager V7:[/B] Geçerli Mods-Center V7 kurulumu varsa mevcut runtime korunur ve benimsenir.
[*][B]Modern yerel kitaplık:[/B] Theme Manager V7 veya modern Themes sürümlerinde Xiaomi Temalar’ın yerel kitaplık/import yolu kullanılır.
[/LIST]

Root modülü kurulu değilse ve geçerli bir harici V7 runtime bulunamazsa cihaz hedefi algılanır ve Global/Non-Global runtime seçenekleri gösterilir.

Global Root MTZ Import modülü uygulama içinden kurulabilir veya güncellenebilir. Global bridge’in etkinleşmesi için modül kurulumundan sonra cihazın yeniden başlatılması gerekebilir; runtime zaten etkinleşmişse tekrar kurulum gerekmez.

Geçerli bir V7 runtime algılanırsa MTZ Studio kendi Themes APK’sını üzerine yazmaz.
