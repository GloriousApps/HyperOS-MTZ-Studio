# HyperOS MTZ Studio v5.0.0

## Root MTZ Import Module 1.0.0

- Xiaomi Themes Global MTZ Import modülü artık kararlı `1.0.0` sürümündedir ve yapımcı bilgisi `GloriousApps` olarak görünür.
- Global Xiaomi Temalar `3.0.5.6`, `3.0.6.8` ve `3.4.x` uyumluluk yolları otomatik seçilir.
- MTZ Studio’dan uygulanan temalarda Xiaomi Temalar kitaplığında aynı MTZ’nin tekrar tekrar birikmesi düzeltildi.
- Temizleme, tema adına göre değil Xiaomi Temalar’ın içerik hash’ine göre yapılır; yalnızca aynı MTZ’nin eski kopyaları kaldırılır.

## Uygulama

- Uygulama sürümü `5.0.0` oldu.
